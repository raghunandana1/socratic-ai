# Socratic AI

An autonomous, multimodal AI tutoring system for competitive exams (JEE Main, JEE Advanced, NEET UG) built on the Socratic method of guided discovery and inquiry rather than spoon-feeding solutions.

## Key Features

- **Socratic Guidance Philosophy**: Scaffolds learning through progressive, multi-tier inquiry prompts.
- **Autonomous Doubt Portal**: Multimodal notebook photo ingestion with OCR transcription & dynamic diagnostic analysis.
- **Adaptive Reinforcement Learning (RL) Engine**: Exam-isolated difficulty calibration and benchmark scoring.
- **Mastery & Knowledge Graph**: Mapped to comprehensive CBSE, JEE, and NEET syllabus taxonomy.
- **Modern Cinematic UI**: Built with React 18, Vite, Tailwind CSS, Framer Motion, and Three.js canvas.

## Tech Stack (Frontend)

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Animations & Effects**: Framer Motion, GSAP, Lenis smooth scroll
- **3D / Particles**: Three.js
- **Icons**: Lucide React

## Repository Branching Structure

- `main`: Core repository base and production-ready releases.
- `frontend`: Frontend application, UI components, syllabus taxonomy, and interactive simulators.
- `backend`: Backend API, multimodal inference, LLM orchestration, and persistence engine (planned).

## Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
